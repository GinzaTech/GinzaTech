## `01 // WHO AM I`

Mình là **GinzaTech** — một developer thích biến những hệ thống khó hiểu thành sản phẩm dễ dùng, có thể đo đạc và đủ ổn định để chạy ngoài đời thật.

Mình quan tâm tới toàn bộ vòng đời sản phẩm: từ trải nghiệm mobile, API và realtime transport đến performance profiling, automation, security boundary, CI/CD và release. ## `03 // ENGINEERING DNA`

| Principle | What it means in practice |
| :--- | :--- |
| **Evidence > assumptions** | Runtime evidence, reproducible steps and explicit verification boundaries before conclusions. |
| **Reliability is a feature** | Cache recovery, race protection, cleanup, failure states and safe fallbacks belong in the product. |
| **Performance is UX** | Frame time, startup, memory and network behavior matter as much as the final screenshot. |
| **Architecture earns its keep** | Types, modules and boundaries exist to make change safer — never just to look impressive. |
| **Ship the whole loop** | Build → test → observe → release → measure → improve. |
